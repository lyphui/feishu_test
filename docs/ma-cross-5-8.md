# MA5/MA8 金叉死叉：分品类实测与证伪

> 从 [CLAUDE.md](../CLAUDE.md) 的模块表进入。代码：
> [`backtest/strategies/ma_cross.py`](../backtest/strategies/ma_cross.py) +
> [`backtest/scripts/compare_ma_cross.py`](../backtest/scripts/compare_ma_cross.py)

被检验的规则（坊间「超短线纪律」的标准表述）：

- **金叉**：MA5 上穿 MA8 → 买入 / 继续持有
- **死叉**：MA5 下穿 MA8 → 卖出 / 离场
- 补充说法：反应快、适合做严格止损止盈；横盘时假信号多，要**结合量能**看

---

## 1. 怎么测的

```bash
python -m backtest.scripts.compare_ma_cross                 # 六个品类桶 × 八个变体
python -m backtest.scripts.compare_ma_cross --quick         # 只跑核心四个变体
python -m backtest.scripts.compare_ma_cross --offline       # 不联网，只读本地缓存
python -m backtest.scripts.compare_ma_cross --buckets 宽基ETF 高波成长股
python -m backtest.scripts.compare_ma_cross --codes 688256:寒武纪 --no-hk   # 自选标的复查
```

**区间**：2018-01-02 → 2026-08-11（约 8.6 年，含 2018 熊市、2019–21 结构牛、
2022–24 调整）。更早的数据只用于均线预热，不计入统计（`eval_start`）。

**六个品类桶，每桶 5 个标的**（「适合哪种品类」这个问题本身就要求分开报，
混成一个池子取平均得到的数字谁也用不上）：

| 桶 | 成员 |
|----|------|
| 宽基ETF | 510300 沪深300 / 510500 中证500 / 512100 中证1000 / 159915 创业板 / 510050 上证50 |
| 行业ETF | 512880 证券 / 512800 银行 / 512010 医药 / 159928 消费 / 512400 有色 |
| 商品跨境ETF | 518880 黄金 / 513100 纳指 / 513500 标普500 / 513050 中概互联 / 159985 豆粕（2019-09 起） |
| 蓝筹低波股 | 600519 茅台 / 601318 平安 / 600036 招行 / 600900 长电 / 601288 农行 |
| 周期资源股 | 601857 中石油 / 601088 神华 / 601899 紫金 / 603993 洛钼 / 600028 中石化 |
| 高波成长股 | 300750 宁德 / 002594 比亚迪 / 300760 迈瑞 / 300059 东财 / 002230 讯飞 |

**八个变体**：MA5/8、MA5/8+量能过滤、MA5/8 零成本、MA3/8、MA5/10、MA5/20、
MA10/20、MA20/60。后五个是**参数邻域**——单点结果说明不了问题，只有邻域同号
才不是噪音（同 [`backtest/scripts/sweep_params.py`](../backtest/scripts/sweep_params.py) 的判读方式）。

**统计窗口对齐**：所有变体共用同一个 `eval_start` = `--start` 与「最长慢线
（MA60）预热完毕那天」取晚者。策略 `prepare()` 会 dropna 掉均线预热期，
MA60 吃掉的根数远多于 MA8；对 2018 年之后才上市的标的（688256 上市 2020-07、
159985 上市 2019-09），各变体的起跑线会不一样，**连买入持有基准都跟着漂**
——688256 上曾出现同一只票 MA5/8 行的基准年化 40.1%、MA20/60 行 49.9%。
统一到最长的那根之后，八个变体与基准落在同一段区间上。

**成交与成本**：走 `engine.run_backtest`，T+1、次日开盘成交、涨跌停无法成交则顺延。
个股佣金万三（最低 5 元）+ 印花税千一 + 滑点千一；ETF 免印花税，其余相同。

三个必须同时在表里的对照：

1. **买入持有**（主指标是 `年化超额 = 策略年化 − 同窗口买入持有年化`）
2. **零成本**（同一组信号把费用全设为 0，用来分离「信号没用」和「信号有用但被吃光」）
3. **参数邻域**（判断是不是参数没挑对）

### 量能过滤怎么落成规则

`vol_window=5, vol_ratio=1.0`：**金叉当日成交量 ≥ 最近 5 日均量**才买，
否则放弃这个买点，不顺延、不补买；**死叉照卖，不看量能**。

出场纪律一旦附加条件，就会退化成「跌了还找理由拿着」，而止损恰恰是这类
策略唯一真正的风控。所以量能只过滤进场——这是把「结合量能看」落成可回测
规则时，唯一既不引入未来信息、又不破坏纪律的落法。

## 2. 结果

### ① 品类特征（桶内中位数）

| 品类 | 年化波动% | 日收益 ρ1 | 买入持有年化% | 买入持有回撤% |
|------|---------:|---------:|------------:|------------:|
| 宽基ETF | 23.7 | +0.01 | +4.3 | −42.2 |
| 行业ETF | 30.1 | −0.01 | +1.7 | −58.7 |
| 商品跨境ETF | 20.0 | −0.01 | +15.6 | −29.7 |
| 蓝筹低波股 | 27.5 | −0.01 | +10.8 | −47.5 |
| 周期资源股 | 29.5 | −0.04 | +16.2 | −47.2 |
| 高波成长股 | 42.3 | −0.01 | +19.5 | −62.2 |

ρ1 = 日收益一阶自相关。**趋势跟踪要靠正的自相关吃饭**（涨了还涨，均线才追得上）；
六个品类的 ρ1 全部落在 ±0.04 以内，日线层面根本没有可供 5/8 这种长度捕捉的动量。
这不是「哪类适合」的问题，而是这个决策频率上**没有东西可吃**。

### ② 年化超额%（桶内中位数，正 = 跑赢买入持有）

| 品类 | MA5/8 | +量能 | 零成本 | MA3/8 | MA5/10 | MA5/20 | MA10/20 | MA20/60 |
|------|------:|-----:|------:|------:|-------:|-------:|--------:|--------:|
| 宽基ETF | −11.1 | −7.0 | −6.7 | −6.2 | −6.3 | −3.9 | **−1.3** | −5.2 |
| 行业ETF | −6.6 | −2.5 | −2.1 | −3.6 | −4.4 | −3.8 | **−0.1** | −4.6 |
| 商品跨境ETF | −11.9 | −12.4 | −7.5 | −14.1 | −11.5 | −4.7 | −6.2 | −5.8 |
| 蓝筹低波股 | −13.0 | −11.5 | −6.1 | −12.9 | −8.7 | −9.1 | −10.6 | −6.5 |
| 周期资源股 | −11.0 | −16.0 | −5.0 | −9.8 | −6.6 | −14.9 | −10.8 | −14.5 |
| 高波成长股 | −17.6 | −11.2 | −10.8 | −15.7 | −17.5 | −3.5 | −9.3 | −3.5 |

**逐标的看：MA5/8 在 30 个标的上 0 个跑赢买入持有**，超额中位数 −11.0%/年，
最好的一只（中国石油）也是 −1.5%。胜率中位数 36%，平均持仓 7.2 个交易日。

参数邻域全为负（最好的一格是 MA10/20 在行业ETF 上的 −0.1%），说明**不是 5/8
挑错了参数**，而是这一类规则在这段样本上整体不成立。放慢参数只是少亏一点：
MA10/20 有 6/30 转正、MA20/60 有 3/30，仍远谈不上有效。

### ③ 交易频率与成本（桶内中位数）

| 变体 | 交易次数/年 | 成本%/年（个股桶） |
|------|----------:|-----------------:|
| MA5/8 | 17.7–18.4 | 6.0–6.4 |
| MA5/8+量能 | 7.9–9.8 | 2.0–3.3 |
| MA5/20 | 7.3–8.7 | 1.9–2.9 |
| MA20/60 | 2.2–2.8 | 0.6–1.0 |

MA5/8 一年约 18 个来回，**光手续费每年就吃掉本金的 4.4%（ETF）到 6.4%（个股）**。
「成本%/年」按窗口内平均权益折算，量纲与年化收益可比。

### ④ 信号本身有没有用（零成本对照）

| 品类 | 实盘成本下超额% | 零成本下超额% | 成本吃掉% |
|------|-------------:|------------:|--------:|
| 宽基ETF | −11.1 | −6.7 | 4.4 |
| 行业ETF | −6.6 | −2.1 | 4.4 |
| 商品跨境ETF | −11.9 | −7.5 | 4.4 |
| 蓝筹低波股 | −13.0 | −6.1 | 7.0 |
| 周期资源股 | −11.0 | −5.0 | 6.0 |
| 高波成长股 | −17.6 | −10.8 | 6.8 |

**零成本下六个桶依然全负。** 这是整份实测最重要的一格：手续费只解释了大约
一半的亏损，另一半来自信号本身——把佣金降到零、滑点降到零，这套规则在
A 股/ETF 上仍然跑不赢躺着不动。省手续费救不回来。

### ⑤ 「严格止损」并没有换来更小的回撤

| 品类 | MA5/8 策略回撤% | 买入持有回撤% |
|------|--------------:|------------:|
| 宽基ETF | −60.8 | −42.2 |
| 行业ETF | −57.6 | −58.7 |
| 商品跨境ETF | −27.0 | −29.7 |
| 蓝筹低波股 | −48.7 | −47.5 |
| 周期资源股 | −55.8 | −47.2 |
| 高波成长股 | −60.0 | −62.2 |

**30 个标的里有 17 个策略回撤比买入持有更深**，在场比例还只有约 50%。
死叉离场确实躲开了单次大跌，但一年十几次「割在底部、追在反弹」的假信号
会累积成更深的净值回撤——这与「短均线适合做严格止损」的直觉正好相反。

量能过滤是这份实测里唯一稳定有效的改良：交易次数腰斩（18 → 8）、成本减半、
回撤中位数从 −54.9% 收到 −38.5%、超额中位数从 −11.0% 抬到 −8.4%。
**它是有效的减损，不是转正。**

### ⑥ 港股 ETF：最低佣金把日频直接判死刑

3175.HK（三星原油期货 ETF），10 万港币本金，中银香港零售口径
（佣金 0.25%、**最低 HK$100/笔**、平台费 HK$30，ETF 免印花税）：

| 变体 | 年化% | 年化超额% | 最大回撤% | 交易次数/年 | 成本%/年 |
|------|-----:|--------:|---------:|----------:|--------:|
| MA5/8 | −13.3 | −10.7 | −80.9 | 18.0 | **16.2** |
| MA5/8+量能 | −6.1 | −3.5 | −53.9 | 7.6 | 6.7 |
| MA5/8 零成本 | +2.9 | **+5.6** | −58.9 | 18.0 | 0.0 |
| MA5/20 | −1.3 | +1.4 | −73.3 | 7.7 | 6.8 |
| MA10/20 | +0.1 | +2.8 | −62.4 | 7.2 | 6.5 |
| MA20/60 | −0.3 | +2.3 | −50.3 | 2.6 | 2.3 |
| 参照：月频 MA150+15% 移动止损 | **+4.5** | +7.2 | −52.1 | 3.8 | — |
| 参照：买入持有 | −2.7 | — | −89.6 | — | — |

这是全场唯一「信号本身有正超额」的地方（零成本 +5.6%）——原油期货 ETF 的
趋势段够长——但 **10 万港币本金下每笔最低佣金 HK$100 ≈ 单边 0.1%，
一年 18 个来回把 16% 的本金交给了券商**，正超额被吃得一点不剩。
同一个标的换成月频决策（每年 3.8 次）就能留下 +4.5% 的年化，
与 [docs/hk-oil-etf-trend-stop.md](hk-oil-etf-trend-stop.md) 的既有结论一致：
**决策频率比均线长度重要得多。**

这是全套实测里 MA5/8 输得最惨的一只：**躺着不动年化 +48.8%，做 5/8 只剩

不能拿它当"找到了合适参数"的证据（判读方式同 `backtest/scripts/sweep_params.py`）。

## 3. 结论

1. **MA5/8 金叉死叉在这段样本上不成立**：30 个标的 0 个跑赢买入持有，
   超额中位数 −11%/年；参数邻域全负，不是「参数没调对」。
2. **手续费只是一半原因**：零成本对照下六个桶仍全负，信号本身没有 alpha。
   六个品类的日收益自相关都在 ±0.04 内，日线上就没有短均线能吃的动量。
3. **它也不是风控工具**：一半以上标的的策略回撤比买入持有更深。
4. **「结合量能」有用，但只是减损**：交易次数与成本腰斩、回撤明显收窄，
   超额仍为负。
5. **要用均线，把频率放慢**：MA20/60 一年交易 2.5 次、成本降到 1% 以内；
   港股原油 ETF 上月频 MA150+移动止损能做到 +4.5% 年化。
   有效的从来不是「哪两根均线」，而是**每年做几次决策**。
6. **对港币账户尤其危险**：最低佣金 HK$100 让日频策略在 10 万港币本金上
   每年凭空损失约 16%。港股账户上任何「超短线纪律」都要先算这笔账。

### 局限

- 每桶 5 个标的，桶内中位数的置信度有限，看的是**桶间方向**而非精确数值。
- 区间固定 2018-01 至今；换区间数字会变，但「越频繁越贵、日线无动量」
  这两个机制不依赖具体区间。
- 策略是二元满仓（金叉全仓、死叉空仓），不含仓位管理与分批。
- ETF 行情为 **qfq 口径**（东财源时通时断，稳定可得的 yfinance 只有前复权），
  分红后历史价会回算，数字不像个股桶的 hfq 那样长期逐位可复现；
  对比值型的均线交叉信号影响很小。
- 高价股（如茅台后复权价过万）按窗口首日价把本金放大到至少买得起 30 手，
  否则整手约束会让引擎一次都不成交。放大本金不改变信号，只消除粒度失真。
