# 单票打法对比台（`stock_playbook.py`）

> 从 [CLAUDE.md](../CLAUDE.md) 的模块表进入。代码：
> [`backtest/stock_playbook.py`](../backtest/stock_playbook.py)

`ma_cross_bench.py` 比的是**同一个策略家族在不同品类上**的表现；这里反过来，
比**同一只票上的不同打法**。三套模拟器（`engine` / `lib.ladder` /
`lib.trend_stop`）本来就在仓库里，缺的只是把它们摆到同一张表、同一段数据、
同一套成本口径上——散在三个脚本里各跑各的，数字没法直接比大小。

```bash
python backtest/stock_playbook.py --code 688256 --name 寒武纪 --start 20200101
python backtest/stock_playbook.py --code 601899 --start 20180101 --offline
```

## 对比的打法

| 类别 | 打法 | 来源 |
|------|------|------|
| 满仓类 | 一次性满仓持有（基准）、定投 10 期/21 日 | `lib.ladder` |
| 分批 / 仓位管理 | 梯度 4×8%（长持 / 半止盈30 / 移动止损25）、底仓50%+网格5×7%、按状态自适应 | `lib.ladder` |
| 趋势跟踪 | 月频 MA100/150/200 ×（无止损 / 移动止损25%） | `lib.trend_stop` |
| 择时对照 | 日频 MA5/8、MA20/60 交叉 | `engine` + `strategies.ma_cross` |

**口径**：行情 hfq；三套模拟器共用 `lib/costs.py` 的费率；涨跌停幅度按代码
前缀推断（科创板/创业板 20%——`lib.ladder` 默认是主板 10%，对 688/300 的票
必须显式传 `limit_pct`，否则本可成交的单子会被判成封死）。`trend_stop` 是
收盘价撮合、按比例扣费的简化模型，与前两套的整手撮合略有出入，**看量级与
排序，不要比小数点后一位**。

**统计窗口对齐**：`ladder` / `trend_stop` 从数据首日就有净值，引擎那两行要等
`prepare()` 的 dropna 走完（MA20/60 = 59 根）。所以统计窗口一律从
`eval_start_of(df)`（= 最长慢线预热完的那天）起算，三类结果再由
`window_stats()` 从「净值 + 仓位序列」**统一重算**指标——各模拟器自带的
`sharpe` / `annual_return` / `deployed_return` 口径并不相同（有的按交易日折年、
有的按自然日；「投入资金收益」对 ladder 是按投入资金、对择时类是按在场比例），
不重算就等于按公式排序而不是按表现排序。

`窗口内笔数` 只数窗口内的成交（买卖各一笔）；满仓持有与梯度长持的底仓建在
预热期，显示 0 是「窗口内没再动手」，不是「从没建仓」。

**怎么读**：高波动个股上「总收益最高」几乎总是满仓持有——它吃满全部涨幅，
代价是吃满全部回撤。必须同时看 **最大回撤**、**平均仓位**、
**投入资金收益**（按实际压上去的钱算）三列。

## 输出的四张表

| 表 | 内容 |
|----|------|
| ① | 全区间打法对比 |
| ② | 阶段划分：连续 ≥20 个交易日的段落（`--min-days` 可调），含起止日期与区间涨跌 |
| ③④ | 分阶段年化% / 累计%：每个打法的日收益按**当日**市场状态分组（三档合并） |
| ⑤ | **逐阶段区间收益%**：② 里的每一段单独算，行=阶段、列=打法，首列是标的自身该段涨跌 |

③④ 与 ⑤ 的区别值得说清楚：③④ 把「所有趋势上行的日子」合并成一个数，回答
「这个打法在这类行情里大致如何」；⑤ 按时间顺序逐段展开，回答「2021 那次下跌
和 2024 那次下跌，同一个打法差多少」。**⑤ 的每个数都是段内连续时间的收益，
是真实可实现的**；③④ 的合并需要「状态切换瞬间无成本进出」这个假设。

阶段来自 `lib/regime.classify`（趋势上行 / 宽幅震荡 / 趋势下行），全 rolling
且带 5 天滞回，**标签当天可知**，按它分组不构成未来函数。但 ③④ 是**归因**
不是可交易策略：同一状态的日子在时间上并不连续，连乘等于假设能在状态切换
瞬间无成本进出。真按状态切换的结果看「自适应」那一行——带成本、带滞回。

表末还会打印 `regime_stats`（各状态之后 60 日的收益分布），用来检验标签本身
有没有信息量：三档若长得一样，按它切换只会白付摩擦成本。

## 实测留档：寒武纪 688256

年化波动 69.7%，日收益 ρ1 +0.059，单日振幅 +29.0% / −20.0%；
市场状态占比：宽幅震荡 58%、趋势走坏 24%、趋势上行 18%。
本金按首日后复权价放大到 75 万（够买 30 手）。

**两个起点各跑一遍**——只跑一个起点，最优格几乎必然是起点红利。
两次的统计窗口分别自 2020-10-19 与 2022-04-06 起（各去掉 59 根预热）：

| 打法 | 2020 起 收益% / 回撤% / 夏普 | 2022 起 收益% / 回撤% / 夏普 |
|------|---------------------------:|---------------------------:|
| 一次性满仓持有（基准） | +894.9 / −76.0 / 0.90 | **+2558.8** / −61.0 / 1.39 |
| 定投 10 期/21 日 | +893.8 / **−63.1** / 0.93 | +2358.0 / −59.4 / **1.40** |
| 梯度 4×8% 长持 | +811.9 / −69.5 / 0.90 | +2413.5 / −60.1 / 1.39 |
| 梯度 4×8% 半止盈30 | +94.0 / −49.6 / 0.46 | +178.7 / −30.4 / 0.93 |
| 梯度 4×8% 移动止损25 | +250.4 / −65.2 / 0.67 | +419.3 / −34.3 / 1.22 |
| 底仓50%+网格5×7% | +439.4 / −64.1 / 0.82 | +1061.5 / −40.6 / 1.30 |
| 自适应（按状态切换） | +354.3 / **−46.0** / 0.93 | +500.5 / **−30.4** / 1.29 |
| 月频 MA200（无止损） | **+1015.6** / −61.8 / **1.01** | +1015.6 / −61.8 / 1.17 |
| 月频 MA150（无止损） | +696.0 / −54.8 / 0.91 | +696.0 / −54.8 / 1.06 |
| 日频 MA5/8 交叉 | +94.9 / −70.4 / 0.44 | +389.3 / −62.0 / 0.90 |
| 日频 MA20/60 交叉 | +131.3 / −60.6 / 0.50 | +368.8 / −54.3 / 0.87 |

（月频那几行两列数字相同：MA200 要 200 根预热，两次运行的首笔建仓都落在
2023-02，此后两段窗口的持仓序列完全一致。不是「2022 年前就已建仓」。）

### 三条在两个起点上都成立的结论

1. **择时打不赢「始终在场」**。日频 MA5/8 是全表垫底档（+94.9% / +389.3%，
   而基准 +894.9% / +2558.8%）；月频均线在 2020 起点上看似最优（MA200 +1015.6%），
   换到 2022 起点就跑输基准 1500 个百分点——那个「最优」是起点红利，不是 edge。
2. **分批建仓换的是回撤，不是收益**。定投在 2020 起点上收益与满仓几乎相同
   （+893.8% vs +894.9%）却把回撤从 −76.0% 收到 −63.1%，夏普 0.93 vs 0.90；
   在 2022 起点上收益反而少 200 个百分点（+2358.0% vs +2558.8%），夏普持平。
   **它是风险管理工具，不是收益增强工具**——起点之后立刻单边上涨时，
   分批必然踏空一截。梯度长持同理。
3. **止盈与止损在这只票上是灾难**：半止盈30 把 +2558.8% 打成 +178.7%，
   移动止损25 打成 +419.3%。年化波动 70% 的票，25% 的回撤是家常便饭，
   止损只会在洗盘里被反复打掉，然后眼看着主升段没有自己的份。

### 分阶段拆解（2020-07 起）

阶段占比（统计窗口内）：趋势上行 270 天（19%）、宽幅震荡 788 天（56%）、
趋势下行 356 天（25%）。

**分阶段年化%**（同状态的日子拼起来折年）：

| 打法 | 趋势上行 | 宽幅震荡 | 趋势下行 |
|------|--------:|--------:|--------:|
| 一次性满仓持有 | +146.5 | +53.1 | −4.4 |
| 定投 10 期/21 日 | +121.1 | **+60.0** | −2.6 |
| 梯度 4×8% 长持 | +123.1 | +53.2 | −2.7 |
| 梯度 4×8% 半止盈30 | +41.4 | +8.3 | +0.2 |
| 梯度 4×8% 移动止损25 | +148.5 | +10.2 | −4.0 |
| 底仓50%+网格5×7% | +100.4 | +35.7 | −4.1 |
| 自适应（按状态切换） | +110.8 | +22.4 | **+3.0** |
| 月频 MA200（无止损） | +146.7 | +45.2 | **+21.9** |
| 月频 MA150（无止损） | +146.7 | +43.4 | −1.3 |
| 日频 MA5/8 交叉 | **+9.2** | +27.7 | −16.5 |
| 日频 MA20/60 交叉 | +173.1 | +4.3 | −22.9 |

三个值得记下来的读数：

1. **MA5/8 在最该赚钱的阶段几乎不赚**：趋势上行期年化只有 +9.2%，而躺着不动
   是 +146.5%。5 日线太敏感，主升段里随便一次回调就把人甩下车，再追回来已经
   涨了一截；到了趋势下行期它又比满仓亏得更多（−16.5% vs −4.4%）。两头都不占，
   这正是全区间垫底的来源。
2. **「均线策略赚趋势的钱、亏震荡的钱」这句话在这只票上是反的**：MA5/8 在震荡期
   （+27.7%）反而比上行期（+9.2%）好看。原因是这只票的「宽幅震荡」788 天里
   累计涨了 +278.3%——标签叫震荡，实质是慢牛，谁在场谁赚钱。
3. **低频趋势跟踪的全部价值都在下行期**：月频 MA200 是唯一在趋势下行期为正的
   打法（+21.9%），它避开了 2021-08 → 2023-02 那段 −18.5% 的下跌。上行期它和
   满仓持有几乎一样（+146.7% vs +146.5%，因为那段时间它就是满仓）。

| 04 趋势上行 23-03→23-05（41日） | +140.6 | +140.4 | +114.1 | +116.2 | +140.6 | **+70.1** | +138.3 |
| 05 宽幅震荡 23-05→24-04（235日） | −29.0 | −29.0 | −26.4 | −26.6 | **−47.6** | −30.1 | −37.3 |

| 12 宽幅震荡 25-05→25-08（65日） | +38.7 | +38.7 | +37.6 | +37.7 | +38.7 | **+47.4** | +35.9 |

合并表看不到、逐段表才看得到的四件事：

1. **08 段是全表最刺眼的一格**：标的三个月涨 68.2%，MA5/8 拿到 **−1.5%**。
   主升段被震荡打出来，追回去时段落已经结束——这就是「趋势上行期年化只有
   +9.2%」的具体长相。
2. **月频 MA200 的 +16.7%（02 段）是它全部超额的来源**：那 346 天标的跌 17.2%，
   它空仓躲过。但同一个打法在 05 段（标的 −29.0%）反而亏 −47.6%，比标的还差
   ——均线在震荡里反复进出，低频也不能幸免。**它不是稳定的保护，只在一次
   长下跌里生效过一次。**
3. **定投的优势集中在 01 段**：标的 −46.7%，定投只有 −36.9%，比满仓少亏
   13 个百分点。其余段落它和满仓几乎贴着走，涨段还要少赚一点。也就是说，
   分批的价值全在「起点买贵了」这一件事上，而不是持续的择时能力——这也是
   全区间它收益打平、只有回撤更浅的原因。
4. **MA5/8 也有跑赢的时候**（12 段 +47.4%、14 段 +56.8%），但和它输的段落
   一样没有规律可循。这正是「单看今年 YTD 会得出相反结论」的原因。

### 但别据此做状态切换

同一份输出里的 `regime_stats` 给了反证：三个状态之后 60 日的收益分布是

| 状态 | 天数 | 未来 60 日均值 | 中位 | 胜率 |
|------|-----:|-------------:|-----:|-----:|
| 趋势上行 | 228 | +27.3% | +6.0% | 55.3% |
| 宽幅震荡 | 829 | +17.1% | −2.2% | 47.4% |
| 趋势下行 | 356 | **+22.3%** | +3.7% | **57.9%** |

「趋势下行」之后的未来收益反而比「宽幅震荡」更好、胜率最高——**这个标签对
未来没有可靠的区分度**。所以上面的分阶段表只能用来解释「过去的收益是在哪些
阶段挣到/亏掉的」，不能倒过来当成「识别出下行期就减仓」的依据。

### 降回撤只有一条路：少拿一点

回撤最浅的三个打法（自适应 −30.4%、移动止损25 −34.3%、网格 −40.6%，
均为 2022 起点）共同点是**平均仓位只有 30~35%**。它们不是「更聪明的择时」，
本质是「仓位更轻」——收益也随之砍掉 60~80%。

所以「扛不住 −60% 回撤」的正确解法不是给这只票加择时规则，而是**降低它在
组合里的权重**：拿 30% 仓位满仓持有，和拿 100% 仓位做移动止损，回撤量级
相当，但前者不承担被反复洗出去的风险，也不用天天盯盘。

### 局限（重要）

- 这段历史里寒武纪是 8~16 倍的大牛股，**任何「始终在场」的打法都会赢**。
  上面的排序只说明「在一只事后看长期向上的票上该怎么拿」，对「这只票未来
  还会不会涨」没有任何预测力。买入持有与分批建仓的前提都是标的本身长期向上。
- 单票、两个起点，样本仍然很小；`n_trades` 个位数的那几行（月频 5~9 笔）
  尤其不能当统计结论。
- 定投的优势部分来自两段样本都是「先跌后涨」。起点之后立刻上涨时它就会
  跑输一次性满仓——2022 起点上正是如此（+2358.0% vs +2558.8%）。
- 表 ① 的数字对**统计窗口起点**敏感：窗口一律从「最长慢线预热完」那天起算
  （见上文「统计窗口对齐」）。早期版本让各打法各按自己的窗口出数，
  同一只票的买入持有会给出 +703% / +606% / +834% 三个值，表底「几个打法跑赢
  满仓持有」的计票也随之失真。改口径后 2020 起点的买入持有由 +719% 变为
  +894.9%，「定投跑赢满仓」这条结论也随之作废（实为收益打平、回撤更浅）。
